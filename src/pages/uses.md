This is an informal list of the hardware, software, and tools that I use in my daily work or hobbies. Inspired by [nicknisi.com/uses/](https://nicknisi.com/uses/).

## Development Environment

### OS

- Windows 11 with most development work done via [WSL2](https://learn.microsoft.com/en-us/windows/wsl/install)
- [Omarchy](https://omarchy.org/) - testing it out on my laptop, but I still need Office and the Adobe suite for work, so not quite ready to make the jump yet

### Editor

-   [Visual Studio Code](https://code.visualstudio.com/) or [Zed](https://zed.dev/) - I use VS Code for most development, but Zed when I want to use local AI
-   [Dark (Visual Studio)](https://vscodethemes.com/e/ms-vscode.cpptools-themes/2017-dark-visual-studio-cc?language=javascript) - colour theme
-   [Cascadia Code](https://github.com/microsoft/cascadia-code) - font
-   Trying out [NeoVim](https://neovim.io/), but it just isn't right on Windows

### Terminal

-   [Windows Terminal](https://github.com/microsoft/terminal)
-   [gh](https://github.com/cli/cli) to interact with `git` and `github`
-   AI Harnesses:
    -   [Claude Code](https://claude.com/product/claude-code) - my preferred agent harness, used with the Claude Max plan
    -   [Codex](https://openai.com/codex/) - only using it to try out the Plus plan
    -   [OpenCode](https://opencode.ai/) - great all rounder, will likely settle on this with [OpenCode Go](https://opencode.ai/go)
-   Package Managers:
    -   [`pip`](https://pypi.org/project/pip/)also using [uv](https://docs.astral.sh/uv/) in some cases
    -   [`npm`](https://www.npmjs.com/)
    -   [`homebrew`](https://brew.sh/) for packages on Ubuntu/WSL
    -   [`winget`](https://github.com/microsoft/winget-cli) - to replace the Windows Store

## Browser

-   [Firefox](https://www.firefox.com/) - fast, performant, privacy-focused, no overbearing AI features
-   [Chrome](https://www.google.com/chrome/index.html) - some media formats only like Chrome, so I keep this as a backup

### Extensions

-   [uBlock Origin](https://ublockorigin.com/) - content blocker
-   [Bitwarden](https://bitwarden.com/) - password manger, have a self-hosted instance for backup
-   [WhatRuns](https://www.whatruns.com/) - see the tech behind a website
-   [FoxyTab](https://addons.mozilla.org/en-US/firefox/addon/foxytab/) - adds a bunch of power features to Firefox Tabs
